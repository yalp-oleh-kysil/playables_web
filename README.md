# Playables — веб-програвач плеєблів

Працює в браузері на iPhone, Android і комп’ютері. Додаєш `.html` або `.zip` — тапаєш — грає на весь екран.
Плеєбли зберігаються тільки на тому пристрої, куди їх додали, на сервер нічого не відправляється.

## Як викласти (GitHub Pages, безкоштовно)

1. github.com → **New repository** → назва, наприклад, `playables` → **Public** → **Create repository**.
2. **uploading an existing file** → перетягни всі файли з цієї папки → **Commit changes**.
3. **Settings → Pages** → Branch: **main**, папка **/ (root)** → **Save**.
4. За 1–2 хвилини там з’явиться адреса `https://<твій-логін>.github.io/playables/`.

## Як відкривати

- **iPhone / iPad:** Safari → адреса → «Поділитися» → «На початковий екран». Відкривай з іконки — тоді без панелей Safari.
- **Android:** Chrome → меню ⋮ → «Встановити застосунок» або «Додати на головний екран».
- **Комп’ютер:** просто відкрий адресу; файли можна перетягувати у вікно.

## Що вміє

- `.html` і `.zip` (з папками всередині: `fetch`, json, картинки, звук, відео працюють як на сервері).
- Однойменний файл замінює старий — зручно перезаливати білди.
- **SDK** — емуляція MRAID 3.0, ironSource `dapi`, Meta `FbPlayableAd`, Google `ExitApi`, Mintegral, Vungle. Плеєбл отримує `ready`/`viewableChange` як у мережі.
- CTA нікуди не веде — внизу з’являється підказка `🛒 CTA → …`. JS-помилки теж показуються.
- **↻** — перезапуск з чистим localStorage, **✕** або Esc — закрити.

На iPhone годинник і батарея лишаються видимими поверх плеєбла — iOS не дозволяє вебзастосункам їх ховати.
